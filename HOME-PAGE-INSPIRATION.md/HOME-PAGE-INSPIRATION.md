# Home page inspiration

Keep the supplied portfolio screenshot as a reference for future home page work.

## What to carry forward

- Use a quiet, warm off-white canvas with generous open space.
- Keep the navigation small, restrained, and aligned to the page edges.
- Let a large, high-quality project image anchor one side of the hero while an editorial title and short supporting copy sit opposite it.
- Align the image and text as a balanced pair, with a fine vertical rule beside the text.
- Use expressive serif typography for the project title and readable, understated supporting text.
- Keep controls and social links discreet so the featured work remains the focus.

Adapt these ideas to Saideep's portfolio content and design system; use the screenshot as inspiration rather than copying it literally.
